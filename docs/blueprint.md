# **App Name**: Seva Local

## Core Features:

- OTP Authentication: Phone number-based authentication with mocked OTP verification for quick access.
- Role Selection: Users select their role (Worker/Customer) via large, icon-driven cards.
- Worker Skill Tag Selector: Workers choose skills from an icon grid (Plumber, Electrician, etc.).
- Voice Intro Recording: Workers record a brief voice introduction instead of typing a bio.
- Aadhar Verification (Placeholder): Workers can upload an Aadhar photo for verification (placeholder implementation).
- Job Creation Form: Customers describe their needs by category (icon grid) and audio/video explanation.
- Hyperlocal Worker Matching: Workers are shown ordered by proximity and rating.
- WhatsApp Integration: Customers connect with workers via WhatsApp deep links with pre-filled messages.
- PWA Offline Caching: PWA Service Worker caches 'My Earnings' and 'Job History' for offline access.

## Style Guidelines:

- Primary color: Vibrant orange (#FF7043) for visibility and energy, aligning with the need for clear visuals in varying lighting conditions.
- Background color: Light, desaturated orange (#FFE0B2) to complement the primary color without overpowering it, ensuring readability and focus on key elements.
- Accent color: Deep blue (#1E88E5) provides a strong contrast to the orange, making it ideal for interactive elements and important calls to action.
- Body and headline font: 'PT Sans', a humanist sans-serif offering a blend of modern aesthetics and a touch of warmth, making it ideal for use for readability in a diverse user group
- Use large, distinct Lucide React icons for job categories and key actions.
- Full-width buttons (minimum 48px height) and a mobile-first responsive design (360px width).
- Subtle transitions for loading states and user feedback.
